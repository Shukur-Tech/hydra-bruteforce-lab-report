# Detailed Lab Notes

## Introduction
A brute force attack is a method used to guess passwords by trying many possible combinations until the correct one is found.

## Lab Setup
The lab was conducted on Kali Linux using Hydra against a local SSH service.

## Procedure Summary
1. Created a small password wordlist
2. Checked SSH service status
3. Started SSH service
4. Executed Hydra in the local lab
5. Observed the result

## Result Summary
The test completed successfully and demonstrated password guessing attempts against the local authentication service.

## Security Recommendation
Systems should use strong passwords, MFA, and login restrictions to reduce exposure to brute force attacks.
